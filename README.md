# 霍兰德职业兴趣测评（无服务器版）

一个纯前端的 10 题霍兰德（RIASEC）职业兴趣测评小工具，直接打开 `index.html` 即可使用。

## 功能

- 10 题兴趣测评问卷（1~5 分量表）
- 自动计算 R / I / A / S / E / C 六维得分
- 结果页展示：
  - 前三兴趣代码
  - 雷达图可视化
  - 各维度解释文本
- 一键导出 PDF 报告（包含雷达图与解释）

## 技术实现

- HTML + CSS + 原生 JavaScript
- Chart.js（CDN）绘制雷达图
- jsPDF（CDN）导出 PDF

## 使用方式

1. 打开 `index.html`
2. 完成 10 道题
3. 回答完全部题目后，点击“提交并查看测评结果”查看图表和解释
4. 点击“导出 PDF 报告”保存结果
